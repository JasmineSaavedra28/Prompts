# Proyecto: Diario de Estudio 📚

Este repositorio contiene la solución completa del **Laboratorio Práctico - Clase 1** de la materia *Algoritmos y Estructuras de Datos III* (I.S.F.T. N° 151).

---

## 📂 Contenido del Repositorio

- **[`diario-estudio/`](./diario-estudio/)**: Carpeta principal del proyecto con el código fuente y guardarraíles.
  - `index.html`
  - `styles.css`
  - `app.js`
  - `AGENTS.md`
  - `MEMORY.md`
  - `README.md`
- **[`prompts-originales/`](./prompts-originales/)**: Archivos de especificación, prompts y notas de guía originales del laboratorio.

---

## 🚀 Inicio Rápido

Para probar la aplicación web:

1. Ingresa a la carpeta `diario-estudio/`.
2. Abre `index.html` en tu navegador.
